# GeoShield: Landslide Risk & Slope Safety Dashboard

GeoShield is an automated geotechnical hazard assessment dashboard designed to evaluate slope stability and landslide risks using Tier 1 primary screening and Tier 2 advanced engineering parameters.

## Features
- **Tier 1 Screening:** Evaluates slope angle, rock lithology, seismic PGA, soil moisture, and vegetation cover.
- **Tier 2 Expert Analysis:** Integrates shear strength (cohesion & friction), pore water pressure, kinematic discontinuities, and Factor of Safety (FoS).
